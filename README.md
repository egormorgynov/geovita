# GeoVita

Кликабельный демонстрационный прототип внутренней системы планирования закупок и запасов GeoVita.

Прототип помогает за 30–60 секунд понять:

- где возникла проблема;
- почему она появилась;
- что система рекомендует сделать;
- сколько и до какой даты заказать;
- сколько денег находится под риском;
- где требуется решение специалиста.

Опубликован через GitHub Pages.
